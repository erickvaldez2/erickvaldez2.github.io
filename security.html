Securing
my website

I reviewed my own site and domain the way I'd review any small public website, then put protections in place for email, certificates, DNS and the pages themselves.

01

Review

Checked every page, the code, and the domain's public records for gaps.

02

Fix

Added protections to the site's code and the domain's settings.

03

Verify

Re-tested everything to confirm each fix actually worked.

What I added.

  1. Email

    Anti-spoofing

    SPF and DMARC records stop scammers from sending email that pretends to come from my domain.

  2. TLS

    Certificate control

    A CAA record limits which certificate authorities can issue certificates for my domain.

  3. DNS

    DNSSEC

    Signed DNS records help visitors' resolvers detect forged answers that would send them to a fake site.

  4. Pages

    Browser protections

    A Content Security Policy and referrer policy on every page limit what the browser will load and what it shares with other sites.

  5. Code

    Input validation

    Anything a tool on my site reads from a file is checked and cleaned before it reaches the page.

  6. Report

    security.txt

    A standard security.txt file tells researchers how to report an issue.

What I took from it.

  • Verify, don't assume.

    A setting can look right and still be wrong. Re-testing after every change is what catches it.

  • Small sites still get targeted.

    Spoofed email and fake certificates don't need a big target. A domain with your name on it is enough.
